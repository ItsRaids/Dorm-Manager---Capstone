# Dormhub

Dormhub is a household/roommate management app — accounts, shared households, chores, shopping lists, a calendar, group chat, voting, expenses, documents, and more. This README tracks the project roadmap across a 5-week build.

## Stack
- **Backend:** Python
- **Database:** MySQL
- **Frontend:** JavaScript, HTML, CSS

## Roadmap at a Glance

| Week | Theme | Goal |

| [1](#week-1--foundation--household-setup) | Foundation & Household Setup | Build the core application and get users into households |
